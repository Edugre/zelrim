# Zelrim

Experimental Skyrim Special Edition / Ocarina of Time interoperability.
The Windows shared-memory bridge now carries process heartbeats and read-only,
OOT-authoritative Link telemetry. It does not move Link or alter either game's gameplay.

See [transport build, deployment, and runtime verification](docs/transport-foundation.md).

See [milestone 1](docs/milestone-01.md) for the architecture, protocol, build
commands, lifecycle behavior, and tests.

See [milestone 2](docs/milestone-02.md) and its original
[read-only Link telemetry plan](docs/milestone-02-plan.md).

See the [project roadmap and context for future chats](docs/roadmap.md) for the
milestone sequence, architectural boundaries, and handoff guidance.
