# Zelrim

Experimental Skyrim Special Edition / Ocarina of Time interoperability.
The Windows shared-memory bridge now carries process heartbeats,
OOT-authoritative Link telemetry, and read-only Skyrim world telemetry. It does
not move actors or alter either game's gameplay.

See [transport build, deployment, and runtime verification](docs/transport-foundation.md).

commands, lifecycle behavior, and tests.
